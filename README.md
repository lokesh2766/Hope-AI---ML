## Week 3 - Machine Learning Regression

- [Complete Week 3 assignment notebook](Week_3_Machine_Learning_Regression_Assignments.ipynb)
- [Insurance dataset](data/insurance_pre.csv)

The notebook includes:

1. Employee attrition problem identification and a dummy dataset.
2. Insurance-charge regression using five algorithms.
3. Cross-validation, R2, MAE, RMSE, charts, feature importance, and final-model justification.
4. A practical `GridSearchCV` hyperparameter-tuning exercise.

The regression analysis uses a fixed random seed for reproducibility and keeps preprocessing inside scikit-learn pipelines to reduce data leakage.
